Periodic Box

Get the box vectors for a trajectory’s periodic simulation box. These vectors can be used to create periodic images of the trajectory. Matrix holds the same vectors as its columns, so transforming by it converts fractional coordinates of the box to world coordinates, and by its inverse the reverse. The box lengths are in world units, where 1 m is 1 nm, and the angles in degrees, as the trajectory sets them while Update is on.

Inputs

Name Type Description
Update Bool Set the box lengths and angles from the trajectory on every frame change, as the molecule updates its positions. Turn off to set them by hand
a Float Length of box vector A in world units, where 1 m is 1 nm
b Float Length of box vector B in world units, where 1 m is 1 nm
c Float Length of box vector C in world units, where 1 m is 1 nm
alpha Float Angle between box vectors B and C, in degrees
beta Float Angle between box vectors A and C, in degrees
gamma Float Angle between box vectors A and B, in degrees

Outputs

Name Type Description
A Vector Box vector A in world units, along the X axis
B Vector Box vector B in world units, in the XY plane
C Vector Box vector C in world units
Matrix Matrix The box vectors A, B and C as columns, which transforms fractional coordinates of the box into world coordinates

API Reference: nodes.geometry.PeriodicBox

Periodic Cell

Mesh and edges of the periodic unit cell, the box spanned by the box vectors or the compact cell around its centre

Mesh of the periodic unit cell, read from the trajectory on every frame while Update is on. With Wrap set to Box it is the box spanned by the box vectors; with Compact it is the compact (Wigner-Seitz) cell around the box centre, such as a hexagonal prism for a hexagonal box or a rhombic dodecahedron, matching the Wrap of Periodic Offset. Mesh is the closed cell and Edges its edges as curves, for a wireframe with Curve to Mesh. Both are empty without a box.

Inputs

Name Type Description
Wrap Menu The box spanned by the box vectors, or the compact cell around the box centre (GROMACS -ur compact), matching the Wrap of Periodic Offset
Update Bool Set the box lengths and angles from the trajectory on every frame change, as the molecule updates its positions. Turn off to set them by hand
a Float Length of box vector A in world units, where 1 m is 1 nm
b Float Length of box vector B in world units, where 1 m is 1 nm
c Float Length of box vector C in world units, where 1 m is 1 nm
alpha Float Angle between box vectors B and C, in degrees
beta Float Angle between box vectors A and C, in degrees
gamma Float Angle between box vectors A and B, in degrees

Outputs

Name Type Description
Mesh Geometry The closed cell in world units, empty without a box
Edges Geometry The edges of the cell as curves, without the diagonals of its triangulated faces, empty without a box

API Reference: nodes.geometry.PeriodicCell

Periodic Offset

Offset positions through the periodic box and wrap them back inside it

Move positions through the periodic box and wrap them back inside it, as when re-centring a simulation box. With Offset Type set to Factor the Offset Factor is in fractions of the box vectors, so 0.5 moves by half the box whatever its shape or size. With Distance the Offset Distance is in world units, where 1 m is 1 nm. Works for orthorhombic and triclinic boxes, which are read from the trajectory on every frame while Update is on. Without a box the positions are unchanged. Wrap set to Box wraps into the box spanned by the box vectors, a slanted prism for a triclinic box; Compact moves each position to its image nearest the box centre (GROMACS -ur compact), so a hexagonal box keeps its hexagonal prism shape, using a KD-tree over the 27 neighbouring images.

Inputs

Name Type Description
Position Vector Positions to move and wrap into the periodic box
Offset Type Menu Give the offset as a factor of the box vectors, or as a distance
Offset Factor Vector Offset as a factor of box vectors A, B and C, so 0.5 moves by half the box along each
Offset Distance Vector Offset as a distance in world units, where 1 m is 1 nm
Wrap Menu Wrap into the box spanned by the box vectors, or into the compact cell around the box centre, putting each position at its image nearest the centre (GROMACS -ur compact). For a hexagonal box the compact cell is a hexagonal prism
Update Bool Set the box lengths and angles from the trajectory on every frame change, as the molecule updates its positions. Turn off to set them by hand
a Float Length of box vector A in world units, where 1 m is 1 nm
b Float Length of box vector B in world units, where 1 m is 1 nm
c Float Length of box vector C in world units, where 1 m is 1 nm
alpha Float Angle between box vectors B and C, in degrees
beta Float Angle between box vectors A and C, in degrees
gamma Float Angle between box vectors A and B, in degrees

Outputs

Name Type Description
Position Vector Positions offset and wrapped into the periodic box, or unchanged without a box

API Reference: nodes.geometry.PeriodicOffset

Periodic Unwrap

Make groups of atoms whole across the periodic box, such as molecules split by its boundaries

Make groups of atoms whole where the periodic box has split them across its boundaries. Atoms with the same Group ID are kept together: link fragment_id for bonded molecules, or chain_id or ures_id for a topology without bonds. Unlinked, each atom is its own group. Each atom moves to the periodic image nearest the circular mean of its group, so every group must be shorter than half the box. Place Groups wraps the centre of each group into the box, or with Wrap set to Compact into the compact cell around the box centre, as Periodic Offset does; otherwise groups stay where they are, nearest their average position. Uses Periodic Offset.

Inputs

Name Type Description
Position Vector Positions to make whole across the periodic box
Group ID Int Atoms with the same ID are kept whole, such as fragment_id for bonded molecules or chain_id. Each group must be shorter than half the box
Place Groups Bool Wrap the centre of each group into the periodic box. Otherwise each group stays nearest its average position
Wrap Menu With Place Groups, wrap each group centre into the box spanned by the box vectors, or into the compact cell around the box centre, as in Periodic Offset
Update Bool Set the box lengths and angles from the trajectory on every frame change, as the molecule updates its positions. Turn off to set them by hand
a Float Length of box vector A in world units, where 1 m is 1 nm
b Float Length of box vector B in world units, where 1 m is 1 nm
c Float Length of box vector C in world units, where 1 m is 1 nm
alpha Float Angle between box vectors B and C, in degrees
beta Float Angle between box vectors A and C, in degrees
gamma Float Angle between box vectors A and B, in degrees

Outputs

Name Type Description
Position Vector Positions with each group made whole, or unchanged without a box

API Reference: nodes.geometry.PeriodicUnwrap

Symmetry Cubic

Build a tetrahedral (T, 12 copies), octahedral (O, 24) or icosahedral (I, 60) assembly from one copy

Build a cubic assembly from one copy: Group picks tetrahedral (12 copies, as in Dps), octahedral (24, as in ferritin) or icosahedral (60, as in small virus capsids). At zero Orientation the two-folds lie along X, Y and Z with a three-fold along (1, 1, 1), and for icosahedral a five-fold along (0, 1, 1.618); rotate it to match a structure, and set Centre to the point all the axes pass through. Shares the Animate input with Symmetry Cyclic.

Inputs

Name Type Description
Geometry Geometry Geometry to replicate over the group
Group Menu Which cubic point group to build
Orientation Rotation Rotation of the group’s axes. At zero the two-folds lie along X, Y and Z and a three-fold along (1, 1, 1); for icosahedral a five-fold lies along (0, 1, 1.618)
Centre Vector Point all the symmetry axes pass through
Animate Float 0 places a copy back on the original, 1 builds the full symmetry. Evaluated on each copy, so a field such as Stagger Value moves the copies one after another

Outputs

Name Type Description
Instances Geometry

API Reference: nodes.geometry.SymmetryCubic

Symmetry Cyclic

Build a cyclic (Cn) assembly: n copies evenly spaced around one axis

Build a cyclic (Cn) assembly the file does not describe: Order::Integer copies of the geometry evenly spaced about an Axis passing through Centre. Rings, pores and most homo-oligomers. The Animate input interpolates each copy from the original (0) to its final placement (1) for assembly animations. It is evaluated per copy, so Stagger Value moves the copies one after another. Every copy carries a sym_id attribute, readable with the Symmetry ID node.

Inputs

Geometry Geometry Geometry to replicate around the axis
Order Int Number of copies evenly spaced around the axis (the n of Cn)
Axis Vector Direction of the symmetry axis
Centre Vector Point the symmetry axis passes through
Animate Float 0 places a copy back on the original, 1 builds the full symmetry. Evaluated on each copy, so a field such as Stagger Value moves the copies one after another

Outputs

Name Type Description
Instances Geometry

API Reference: nodes.geometry.SymmetryCyclic

Symmetry Helical

Build a helical assembly: each subunit advances along the axis by the rise and rotates about it by the twist

Build a helical filament: Count::Integer subunits, each advanced Rise Angstrom along the Axis and rotated Twist about it, relative to the one before. Actin, microtubules, amyloid and pili. The defaults are actin’s 27.5 Angstrom rise and -166.7 degree twist. Axial Symmetry::Integer repeats each subunit evenly around the axis for filaments with Cn symmetry, such as amyloid built from two protofilaments (C2). Shares the Animate input with Symmetry Cyclic.

Inputs

Name Type Description
Geometry Geometry Geometry to replicate along the helix
Count Int Number of subunits to place along the helix, each repeated Axial Symmetry times around the axis
Rise Float Distance advanced along the axis per subunit, in Angstrom
Twist Float Angle rotated about the axis per subunit
Axial Symmetry Int Cn rotational symmetry about the helical axis: each subunit is repeated this many times evenly around the axis, as in filaments built from several protofilaments
Axis Vector Direction of the helical axis
Centre Vector Point the helical axis passes through
Animate Float 0 places a copy back on the original, 1 builds the full symmetry. Evaluated on each copy, so a field such as Stagger Value moves the copies one after another

Outputs

Name Type Description
Instances Geometry

API Reference: nodes.geometry.SymmetryHelical
