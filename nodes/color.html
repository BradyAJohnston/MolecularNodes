Color matplotlib

Colour a Value from 0 to 1 with one of matplotlib’s colormaps. Pick the group with Category, then the colormap from that group’s menu; the other groups’ menus are ignored. Reverse runs the colormap from 1 to 0, like matplotlib’s _r maps. Values outside 0..1 are clamped. Pair with Field Remap or a Map Range node to colour an attribute such as b_factor over its own range. Each colormap is a Color Ramp of at most 32 stops fitted to matplotlib’s colours, within about 1/255 for most maps; a few busy maps such as gist_ncar, nipy_spectral and jet lose some detail, noted in the frame next to each ramp inside the node.

Inputs

Name Type Description
Value Float Position along the colormap, 0 to 1. Values outside are clamped
Reverse Bool Run the colormap from 1 to 0, like matplotlib’s _r maps
Category Menu Group of colormaps, as in matplotlib’s colormap reference
Uniform Menu Perceptually uniform sequential colormap, used when Category is Uniform
Sequential Menu Sequential colormap, used when Category is Sequential
Sequential 2 Menu Sequential (2) colormap, used when Category is Sequential 2
Diverging Menu Diverging colormap, used when Category is Diverging
Cyclic Menu Cyclic colormap, used when Category is Cyclic
Qualitative Menu Qualitative colormap, used when Category is Qualitative
Miscellaneous Menu Miscellaneous colormap, used when Category is Miscellaneous

Outputs

Name Type Description
Color Color Colour of the selected colormap at Value

API Reference: nodes.geometry.ColorMatplotlib

Color Sample Grid

Color each point by the value of a float grid at its position, such as an electrostatic potential from APBS on a Style Surface. Pick the volume object with Object and the grid with Grid Name; densities loaded with Molecular Nodes name their grid density. Values from Min to Max blend linearly from A through Intermediate to B, and values outside the range take the end colors. The default -5 to 5 suits an APBS potential in kT/e. Value outputs the sampled value, trilinearly interpolated, and is zero outside the grid. Densities are stored as 32-bit float grids, as Blender’s grid nodes return zero for 64-bit (DOUBLE) grids. Place it in a Set Color after a style to color the style’s own points (each surface vertex), or before a style to color the atoms by the value at their centres. Pick the density itself in Object, styled or not: density styles turn the volume into a mesh, but Import Volume keeps the grid in the bundle of its output as MN Grid <Name> and the styles pass it on, so the node samples the grid named Grid Name there, otherwise the grid of that name in the object’s own volume. The grid is sampled in world space, so moving either object moves the molecule through the grid.

Inputs

Name Type Description
Object Object Object holding the grid to sample: a density loaded with Molecular Nodes, styled or not, or any volume object
Grid Name String Name of the grid to sample: the Name of the density’s Import Volume node (density by default), or a grid of the object’s own volume
Min Float Grid value mapped to color A, in the grid’s own units (kT/e for an APBS potential)
Max Float Grid value mapped to color B, in the grid’s own units
A Color Color for values at or below Min
Intermediate Color Color for the value halfway between Min and Max. Colors blend linearly from A to Intermediate to B
B Color Color for values at or above Max

Outputs

Name Type Description
Color Color Color mapped from the grid value at each point
Value Float Grid value at each point, trilinearly interpolated. Zero outside the grid

API Reference: nodes.geometry.ColorSampleGrid
