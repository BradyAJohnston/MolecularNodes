Color

Set and manipulate the colors of atoms

Color Atomic Number

Video

Choose the color for an individual atomic_number. Useful for joining with fields and selecting individual elements for coloring

Inputs

Name Type Description
atomic_number Int The atomic_number of to use the selected color for
Color Color The color to use for the specified atomic_number

Outputs

Name Type Description
Color Color The generated color based on the node inputs

API Reference: nodes.geometry.ColorAtomicNumber

Color Attribute Map

Video

Map a value to interpolate between two colors, optionally using an intermediate color. User can specify the Attribute Name that is used for the inerpolation, specifying the start and end values of the interpolation

Inputs

Name Type Description
Color Space Menu
Name String Name of the attribute to map colors to
Min Float Value for the attribute to be the minimum color
Max Float Value for the attribute to be the maxium color
Intermediate Bool Wheter to interpolate through the ‘Mid’ color.
A Color Color mapped to the minimum value of the attribute
Intermediate Color Color mapped to the middle value of the attribute
B Color Color mapped to the maximum value of the attribute

Outputs

Name Type Description
Color Color The mapped color value based on the attribute.

API Reference: nodes.geometry.ColorAttributeMap

Color Attribute Random

Video

Generate a random color, based on the given attribute. Control the lightness and saturation of the color with the inputs.

Inputs

Name Type Description
Name String Attribute to base the random color generation on
Colorspace Menu
Color Seed Int Seed value for the random generation of the colors
HSL Saturation Float Saturlation level for the random color
HSL Lightness Float Lightness value for the generated random color
OKLab Luminance Float
OKLab Chroma Float

Outputs

Name Type Description
Color Color The randomly generated color based on the input attribute

API Reference: nodes.geometry.ColorAttributeRandom

Color OKLab Mix

Mix two colors together using the OKLab color space. The first color is the base color, and the second color is the color to mix in. The mix is done in the OKLab color space, and then converted back to linear RGB color space.

B Color

Color pLDDT

Name Type Description

<70 Color Color for 50 < pLDTT < 70
<90 Color Color for 70 < pLDTT < 90
>90 Color Color for 90 < pLDTT

Outputs

Name Type Description
Color Color Assigned color based on the pLDTT score

API Reference: nodes.geometry.ColorPLDDT

Color Rainbow

Video

Output a rainbow color spectrum along the structure. The rainbow can be generated along each chain in the structure, or along the entire structure. You can offset the strat of the rainbow and chain the color & satuation of the generated colors

Inputs

Name Type Description
Factor Menu
Color Space Menu
Offset Float Offset the starting hue of the rainbow colors. HSV is 0-1 for the entire rainbow, OKLab is -Pi to Pi for the rainbow.
HSL Saturation Float The Saturation value of the rainbow colors
HSL Value Float The Value value of the resulting rainbow colors
OKLab Luminance Float
OKLab Chroma Float

Outputs

Name Type Description
Color Color The generated color

API Reference: nodes.geometry.ColorRainbow

Set Color

Video

Set the Color attribute on the point domain, based on the input Color field. The Selection field limits the setting of the color to the input Selection, with the unselected points keeping their current Color attribute

Inputs

Name Type Description
Atoms Geometry Atomic geometry that contains vertices and edges
Selection Bool Selection of atoms to apply this node to
Color Color Color to apply to the selected atoms

Outputs

Name Type Description
Atoms Geometry Atomic geometry with an updated Color attribute

API Reference: nodes.geometry.SetColor
