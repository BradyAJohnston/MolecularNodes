Geometry

General geometry processing utilities

Best View

The direction from which the most selected points have a clear line of sight past the occluding meshes, as a camera transform

Finds the direction from which the most selected points can be seen past the occluding meshes. Directions spread over a sphere are scored by casting a ray from each selected point back towards the camera and counting the rays that hit nothing, then refined on shrinking rings around the best. Ties go to the direction that shows the selection broadest. Plug a style’s output into Occluders so the view is judged against what will render; point clouds and instances do not block rays. Transform is a camera transform at the centre of the selection, looking down its local -Z along Direction. Stickiness and Previous Direction penalise turning away from a direction already on screen, which is always scored as a candidate. Hysteresis keeps Previous Direction unless the best direction sees that share of the selected points more, so small differences between searches do not move the view.

Inputs

Name Type Description
Target Geometry Geometry whose points should be seen, such as the atoms
Selection Bool The points of Target that should be seen, such as a ligand
Occluders Geometry Meshes that can block the view, such as the output of a style. Point clouds and instances do not block rays
Up Vector Direction kept upright in the view
Stickiness Float Share of the selected points a turn of 180° away from Previous Direction must gain to be worth it. Shorter turns cost proportionally less
Previous Direction Vector Direction currently looked along, which Stickiness favours and which is always scored. Zero for none
Hysteresis Float Share of the selected points the best view must see beyond Previous Direction before leaving it
Directions Int Directions spread evenly over the sphere in the first pass
Refine Int Rings of refinement around the best direction, starting 10° away and shrinking by 0.4 each time
Offset Float How far in Å towards the camera each ray starts, to clear the point’s own geometry

Outputs

Name Type Description
Transform Matrix Camera transform: located at the centre of the selection and looking down its local -Z along Direction
Rotation Rotation Camera rotation looking along Direction
Direction Vector Direction the camera looks along
Centre Vector Centre of the selected points
Visible Int Selected points with a clear line of sight
Count Int Selected points

API Reference: nodes.geometry.BestView

Centre on Selection

Video

Offsets the input points so that their calculated Centroid is on the world origin. If the Group ID input is used this offset is applied on a per-group basis. If the selection is used, only the selected points contribute towards the calculation of the centroid, but all points are still moved

Inputs

Name Type Description
Atoms Geometry Atomic geometry that contains vertices and edges
Selection Bool Selection within the groups to calculate the centroid for, which then affects all other points in the group
Group ID Int Optionally centre the points separately for each group based on the Group ID input

Outputs

Name Type Description
Atoms Geometry Atoms that have been moved to object origin based on their group’s calculated centroid
Offset Vector The calculated vector offset that was applied to the points

API Reference: nodes.geometry.CentreOnSelection

Fade Geometry

Fade geometry in and out by multiplying the alpha of its Color attribute on the point and instance domains. Place it after a style node and animate Fade from 1 to 0 to fade that style out of a scene, or from 0 to 1 to fade it in. The node multiplies the existing alpha, so geometry that is already partly transparent stays proportionally more transparent. Only materials that read the alpha show the fade: Default, Squishy and Ambient Occlusion do, while Flat and Transparent ignore it.

Inputs

Name Type Description
Geometry Geometry Geometry to fade, such as the output of a style node
Fade Float Multiplier for the alpha of the Color attribute. At 1 the geometry is passed through unchanged, at 0 it is removed

Outputs

Name Type Description
Geometry Geometry Geometry with the faded alpha stored in Color

API Reference: nodes.geometry.FadeGeometry

Orient to Best View

Rotate the geometry about the selection so the camera sees it from its Best View

Rotates the geometry about the centre of the selection so the camera sees the selection from its Best View. The meshes of Geometry are the occluders, so put it after the styles. The node follows Camera, or the scene’s active camera when that is empty: orbiting the camera turns the geometry with it, and Factor blends from the original orientation. Turn on Smoothing::Boolean to ease towards each new best view instead of jumping, for trajectories or an animated camera: every simulation step moves the translation and rotation separately by a = lerp(a, b, 1 - 2^(-dt / Half Life)), so the remaining gap halves every Half Life seconds at any frame rate. Stickiness makes the search favour views near the one on screen: each direction loses that share of the selected atoms, scaled by (1 - cos θ) / 2 of its angle θ from the current view, so turning around must gain the whole share. Hysteresis holds the view on screen until a new one sees that share of the selected atoms more. Both work with or without smoothing, and like smoothing they only advance during playback. Turn off Move Geometry::Boolean to leave the geometry in place and move a camera instead: Camera Transform is where the camera goes, relative to this object, for the same view. Store it on the first point of the output and give a second camera a Geometry Attribute constraint that reads it (type 4x4 matrix, Apply Target Transform on). That camera must not also be Camera or the active camera the node falls back to, or each depends on the other.

Inputs

Name Type Description
Geometry Geometry Geometry to rotate. Its meshes are what can block the view
Atoms Geometry Atoms holding the points that should be seen
Selection Bool The atoms that should be seen, such as a ligand
Camera Object Object to orient towards
Factor Float Blend from the original orientation to the best view
Move Geometry Bool Rotate the geometry to the best view. Turn off to leave it in place and move a camera with Camera Transform instead
Smoothing Bool Ease towards each new best view over the simulation instead of jumping. Only advances during playback
Half Life Float Seconds for the remaining gap to the best view to halve
Stickiness Float Favour best views near the one shown: the share of the selected atoms a turn of 180° must gain to be taken. Works with or without Smooth, and only advances during playback
Hysteresis Float Hold the view shown until a new best view sees this share of the selected atoms more. Works with or without Smooth, and only advances during playback

Outputs

Name Type Description
Geometry Geometry
Transform Matrix Transform applied to the geometry
Camera Transform Matrix Where the camera goes, relative to this object, to see the unmoved geometry from the best view. Store it on a point and copy it to another camera with a Geometry Attribute constraint

API Reference: nodes.geometry.OrientToBestView
