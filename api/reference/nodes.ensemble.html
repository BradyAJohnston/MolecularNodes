    geometry=None,
    group='Tetrahedral',
    orientation=None,
    centre=None,
    animate=1.0,
)

Build a tetrahedral (T, 12 copies), octahedral (O, 24) or icosahedral (I, 60) assembly from one copy

GUI reference: Symmetry Cubic.

Parameters

Name Type Description Default
geometry InputGeometry Geometry to replicate over the group None
group InputMenu | Literal['Tetrahedral', 'Octahedral', 'Icosahedral'] Which cubic point group to build 'Tetrahedral'
orientation InputRotation Rotation of the group’s axes. At zero the two-folds lie along X, Y and Z and a three-fold along (1, 1, 1); for icosahedral a five-fold lies along (0, 1, 1.618) None

animate InputFloat 0 places a copy back on the original, 1 builds the full symmetry. Evaluated on each copy, so a field such as Stagger Value moves the copies one after another 1.0

Inputs

i.centre VectorSocket Point all the symmetry axes pass through
i.animate FloatSocket 0 places a copy back on the original, 1 builds the full symmetry. Evaluated on each copy, so a field such as Stagger Value moves the copies one after another

Outputs

Name Type Description
